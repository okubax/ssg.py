Headings, **bold**, *italic*, [links](https://example.com), lists, and
fenced code blocks all work the way you would expect:

```python
print("this came out of a code fence")
```

So does a blockquote:

> Nothing here is doing anything clever. It is just Markdown, turned into
> HTML, dropped into a template.

The front matter above this paragraph set two tags, `meta` and `markdown`.
Each one gets its own page, generated automatically, at
`/tag/meta.html` and `/tag/markdown.html`.
